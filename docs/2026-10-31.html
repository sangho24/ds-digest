Elucidating the Design Space of LM Data Attribution

데이터 기여 원천 추적 정확도 향상 방법 제시

배경과 위치
이 논문은 기존 LLM 데이터 기여 평가가 데이터 속성 혼재로 원인 파악이 어려운 문제를 해결하고자 한다. 합성 지식으로 학습시킨 모델에 대해 하나씩 데이터 변수를 조절할 수 있는 Controlled Attribution Benchmark(CATT)를 제안한다. 또한 손실 함수와 토큰 점수 집계 방식을 재설계해 평가 정확도를 크게 높이며, 데이터 기여 추적 연구 흐름에서 평가 방법론을 한 단계 앞당긴다.
실행가능성 7
깊이 7
  • · 기존 평가는 여러 데이터 속성을 동시에 바꾸어 원인 분석이 어려웠다.
  • · CATT 벤치마크를 통해 문서 중복과 어휘 방해 요소가 기여 추적 성능을 크게 저하시킨다.
  • · 부정 로그오즈 그라디언트와 상위 토큰 집계가 재현율을 35~72%p 향상시킨다.
Action Items
  • 부정 로그오즈 그라디언트를 추천 시스템에 적용해 사용자‑아이템 상호작용 중 예측에 가장 큰 영향을 미치는 요소를 식별한다, 이는 모델 해석성을 높인다.
  • 상위 토큰 집계 방식을 코드 생성 모델에 적용해 생성된 코드 조각에 기여한 원본 토큰을 강조함으로써 디버깅과 품질 검증을 용이하게 한다.
  • CATT와 유사한 합성 벤치마크를 비전 모델에 도입해 인위적인 이미지 라벨을 학습시킴으로써 데이터 증강이나 레이블 노이즈가 모델 기여 추적에 미치는 영향을 독립적으로 평가한다.
