NIFT-SQL: Customer-Supervised Table Scoring for Enterprise Text-to-SQL Retrieval

고객 질문 기반 테이블 검색으로 SQL 자동화 정확도 향상

배경과 위치
기업 환경에서 질문에 필요한 테이블을 찾는 것이 스키마가 방대해질수록 어려워진다. 기존에는 일반 검색이나 단일 모델에 의존했지만, NIFT‑SQL은 고객별 질문 데이터와 메타데이터를 활용해 하이브리드 검색과 대규모 크로스 인코더 점수를 로지스틱 회귀로 결합한다. 이는 텍스트‑투‑SQL 파이프라인에서 테이블 검색 정확도를 크게 높이는 최신 접근이다.
실행가능성 7
깊이 6
  • · 고객별 질문과 스키마 메타데이터만으로 테이블 검색 모델을 학습하면 검색 정확도가 크게 향상된다.
  • · NIFT‑SQL은 하이브리드 검색과 560M 크로스 인코더 점수를 로지스틱 회귀로 결합해 top‑15 정확도를 69‑90% 수준으로 끌어올렸다.
  • · 라벨이 없는 상황에서도 제로샷 8B 리랭커를 추가 특징으로 활용하면 높은 정확도를 유지할 수 있다.
Action Items
  • 고객 질문 기반 테이블 스코어링을 데이터 레이크 카탈로그 검색에 적용해 관련 데이터셋 발견 효율을 높인다.
  • 하이브리드 검색·크로스 인코더·로지스틱 회귀 결합 방식을 마이크로서비스 API 추천 시스템에 도입해 적절한 서비스 엔드포인트를 빠르게 찾는다.
  • 제로샷 대규모 리랭커를 법률 문서 검색에 특징으로 활용해 라벨링 없이도 높은 정밀도 검색을 구현한다.
