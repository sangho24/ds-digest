배경과 위치
대규모 추천 시스템 학습에서는 라이프사이클 오버헤드가 GPU 활용을 크게 제한해 효율적인 학습이 어려웠다. 기존 연구는 주로 모델·알고리즘 개선에 초점을 맞추었지만, 인프라·운영 단계의 손실을 체계적으로 측정·최적화한 사례는 부족했다. 본 논문은 플릿 규모의 오버헤드 분석과 스택 전반에 걸친 최적화를 제시해 시스템‑레벨 효율성 연구 흐름에 새로운 실증적 기여를 한다.

  • · 통신 제거·파이프라인 겹침·동적 형태 처리·자동 튜닝 가지치기·재사용 가능한 PyTorch 2 컴파일 캐시·비동기 체크포인팅·독립 모델 배포·복구 비용 감소 등 전 스택 최적화를 적용해 평균 15.5%·최대 85%까지 ETT%를 개선했다.
  • · 이 최적화들을 전 파이프라인에 배포한 뒤 전체 플릿의 ETT%가 약 80%에서 90% 이상으로 상승했다.
Action Items

  • 재사용 가능한 컴파일 캐시를 배치 추론 서비스에 도입해 모델 로드 시 초기 지연을 줄이고 전체 응답 시간을 단축한다.
  • 데이터 전처리 파이프라인에서 초기화 단계와 데이터 로딩을 겹쳐 실행해 전체 작업 시간과 자원 대기 시간을 감소시킨다.

Prune First, Decide Fast: Scalable Semantic Query Processing with JEVDB

LLM 비용·지연 최소화한 대규모 의미 쿼리 엔진

배경과 위치
기존 의미 데이터베이스는 관계 결정에 LLM을 직접 호출해 높은 지연·비용 문제에 직면했다. JEVDB는 관계형 DB의 세미조인 기법과 경량 결정 모델을 결합해 후보를 크게 줄이고, 필요 시에만 LLM을 사용한다. 이는 의미 쿼리 처리에서 비용 효율성을 크게 향상시키는 새로운 연구 흐름이다.
실행가능성 7
깊이 6
  • · JEVDB는 빠른 타입 결정 모델을 사용해 의미 필터·조인·분류·랭킹을 수행하고, 불확실한 경우에만 생성형 LLM으로 에스컬레이션해 지연과 비용을 크게 낮춘다.
  • · 정확한 Yannakakis‑style 세미조인과 Semantic Bloom Filters를 결합해 후보 쌍을 사전 필터링, 평균 87.4%를 제거한다.
  • · SemBench·Shelob 벤치마크에서 JEVDB‑Flash는 모든 쿼리에서 최저 지연시간을 기록하고, 평균 F1 95.7‑97.5%와 모델 에스컬레이션 55.2% 감소를 달성했다.
Action Items
  • Semantic Bloom Filters를 대규모 전자상거래 추천 시스템의 벡터 검색 전 단계에 적용해 비용이 많이 드는 신경망 재순위화를 크게 감소시킨다.
  • 타입 결정 모델을 스트리밍 로그 분석에 도입해 명확한 이벤트는 즉시 처리하고, 모호한 경우에만 전체 LLM 분석으로 에스컬레이션해 처리 비용을 절감한다.
  • Yannakakis‑style 세미조인 축소를 그래프 데이터베이스의 엣지 탐색 전 단계에 적용해 임베딩 기반 유사도 계산 전에 후보를 필터링, 쿼리 응답 속도를 높인다.
