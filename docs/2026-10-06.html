From Benchmarks to Production: A Text-to-SQL System for Complex Financial Data

금융 DB Text‑SQL로 실서비스 성능 급상승

배경과 위치
기존 Text‑SQL 연구는 Spider·BIRD와 같이 스키마가 얕고 값이 가독성 있는 벤치마크에 초점을 맞추어 왔으며, 금융 실서비스에서는 키가 정수형인 불투명한 스키마와 다중 조인으로 성능이 50% 이하로 떨어졌다. 본 논문은 이러한 격차를 메우기 위해 도메인 특화 lookup 에이전트, 템플릿 검색, 외래키 기반 스키마 프루닝을 결합한 FLINT을 제안하며, 이는 LLM 기반 Text‑SQL 연구에서 실제 운영 데이터베이스 적용 단계로 나아가는 사례이다.
실행가능성 7
깊이 6
  • · 일반 Text‑SQL 모델은 인간이 읽을 수 있는 값과 얕은 스키마에 최적화돼 금융 실서비스에서 불투명한 정수 키와 다중 조인 때문에 50% 이하 성능을 보인다.
  • · FLINT은 (1) 자연어 개념을 질문별 제약으로 변환하는 lookup 에이전트, (2) 전문가가 만든 템플릿을 임베딩 기반으로 검색, (3) 외래키 체인으로 스키마를 프루닝하는 schema linking을 결합한다.
  • · 359개의 실제 금융 질의에 대한 평가에서 FLINT은 동일 LLM 기반 베이스라인을 능가했으며, 실제 서비스에 배포돼 운영 중이다.
Action Items
  • 제품 ID가 숫자로 저장된 전자상거래 카탈로그에 lookup 에이전트를 도입해 사용자 질의를 해당 ID 제약으로 변환하면 검색 정확도가 향상된다.
  • 의료 데이터베이스에서 임상 질의에 맞는 템플릿을 임베딩 기반으로 검색해 자동 SQL 생성에 활용하면 의사들의 데이터 접근 속도가 빨라진다.
  • 보안 로그의 복잡한 스키마에서 외래키 체인을 따라 필요한 테이블만 선택하도록 스키마 링크를 적용하면 분석 쿼리의 복잡도가 감소한다.

침묵형 체스 엔진에 설명 능력을 부여해 모델 효율성을 높인다

배경과 위치
기존 체스 엔진은 뛰어난 실력을 보이지만 설명을 제공하지 못하고, LLM은 설명은 가능하지만 실력이 약했다. 본 논문은 고성능 체스 엔코더와 인스트럭션‑튜닝된 LM을 교차‑어텐션으로 결합하고, Bellman‑유사 반복 증류로 설명과 성능을 동시에 향상시킨다. 이는 제한된 파라미터로 설명 가능한 게임 AI를 구현하는 새로운 연구 흐름이다.

깊이 7

  • · Bellman‑유사 반복 증류 과정을 7회 적용해 설명을 정제하고 Elo를 900점 이상 상승시켰다
  • · 4 B 파라미터만으로도 기존 최첨단 모델을 능가하는 실력과 GPT‑5.6‑Sol 수준의 설명 일관성을 달성했다
Action Items
  • 자율주행 분야에서 LiDAR 인코더와 LM을 교차‑어텐션으로 결합해 주행 결정에 대한 자연어 설명을 생성, 안전 감시를 강화한다
  • 로봇 조작에서 상위 후보 그립 후 상태를 분석해 언어 설명으로 증류하는 반복 증류를 적용해 성능과 해석 가능성을 동시에 향상시킨다
  • 정적 분석 인코더에서 디버깅 개념을 QA 커리큘럼으로 추출하고 이를 코드 어시스턴트 LM에 증류해 오류 수정 이유를 명확히 제시한다
