퀴즈
Q1. JDBC 트랜잭션 관리의 주요 목적은 무엇인가요?
A) 데이터베이스 성능 최적화
B) 데이터 일관성 보장
C) 쿼리 속도 향상
D) 서버 리소스 절약
정답 보기
✓ B) 데이터 일관성 보장
트랜잭션 관리는 ACID 속성을 통해 데이터베이스 상태의 일관성을 유지하는 핵심 기술입니다.
Q2. 캡슐화를 유지하는 트랜잭션 설계에서 중요한 개념은?
A) 모델 재사용
B) 데이터 분할
C) 의존성 분리
D) 쿼리 병렬화
정답 보기
✓ C) 의존성 분리
의존성 분리는 트랜잭션 로직과 비즈니스 로직을 분리해 캡슐화를 유지하는 핵심 전략입니다.
