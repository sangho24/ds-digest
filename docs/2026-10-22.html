NousDB - A Fast Query Engine for Semantic Analytics

LLM 의미 쿼리 엔진, 토큰 최적화로 86배 가속

배경과 위치
기존 의미 분석 시스템은 튜플당 LLM 호출과 ad‑hoc 연산자로 확장성이 떨어졌다. NousDB는 Apache DataFusion 위에 의미 연산자를 추가하고 토큰 히스토그램 기반 비용 모델을 도입해 쿼리 재작성·배치 최적화를 가능하게 한다. 이는 의미 쿼리 처리와 LLM 비용 효율성 연구 흐름에서 배치 규모와 컨텍스트 윈도우 제약을 정량화한 최초 시도이다.
실행가능성 7
깊이 6
  • · 기존 시스템은 per‑tuple LLM 호출과 ad‑hoc 연산자로 확장성이 제한됨
  • · NousDB는 세 가지 의미 연산자를 추가한 확장 관계대수를 제안해 쿼리 재작성과 교차 연산자 최적화를 가능하게 함
  • · Equi‑depth 토큰 히스토그램 기반 비용 모델로 배치 크기를 최적화해 최대 86배 속도 향상을 달성함
Action Items

  • 데이터 레이크 쿼리 엔진에 의미 연산자를 도입해 비정형 문서의 유사도 검색을 선언형으로 수행한다.
  • 다단계 ETL 파이프라인에서 LLM 호출 비용 모델을 활용해 단계별 토큰 사용을 최적화한다.
