배경과 위치
기존 코딩 에이전트 평가는 정적 이슈·명령에 의존해 실제 앱 동작을 반영하지 못했다. ProgramDistill는 완전 동작하는 레퍼런스 앱에서 기능을 추출해 재생 검증 가능한 과제를 자동 생성함으로써, 인터랙티브 웹 앱 기반 작업 재구성을 평가한다. 이는 대규모, 난이도 조절 가능한 벤치마크를 제공해 에이전트 개발 흐름에 새로운 평가 단계와 커리큘럼 설계 기반을 제공한다

깊이 5
  • · ProgramDistill는 앱을 세분화된 기능으로 분해하고 gold patch 로 재생 가능한 행동을 추출해 1,975개 행동·4,063개 과제를 자동 생성한다
  • · GPT-6 Astra와 Claude Opus 5는 전체 재구성에서 각각 49.2%·28.8% 성공률을 보이며, 복원 깊이가 1→8일 때 성공률이 크게 감소한다
  • · 이 벤치마크는 규모와 난이도를 제어할 수 있어 코딩 에이전트 평가·진단 및 커리큘럼 기반 훈련에 활용 가능하다

  • 레거시 시스템 리팩터링 시 기능별 gold patch 를 추출해 점진적 코드 교체와 검증을 지원한다
  • 보안 사고 로그에서 행동 추출 파이프라인을 활용해 사이버 대응 AI 에이전트를 위한 단계별 훈련 시나리오를 만든다

Infinite-Parameter LLMs: Generating and Adapting Weights from Live Data

실시간 데이터로 가중치를 업데이트해 LLM 효율성 향상

배경과 위치
기존 LLM은 사전 학습 후 가중치가 고정돼 실시간 사용자 데이터 학습이 불가능했다. MoE 기반 모델은 파라미터를 효율적으로 활용했지만 정적 데이터에 의존한다. 본 논문은 하이퍼네트워크와 베이지안 온라인 업데이트를 결합해 실시간 데이터로 무한 가중치를 생성·적응시키는 새로운 아키텍처를 제시한다.
실행가능성 5
깊이 6
  • · 하이퍼네트워크가 실시간 데이터로 피드포워드 가중치를 생성하는 Infinite-Parameter LLM을 제안한다.
  • · 생성기의 잠재 코드를 베이지안 신념으로 온라인 업데이트해 세션 중 가중치가 지속적으로 진화한다.
  • · 가중치에 지식을 저장해 컨텍스트 창을 절약하고, 인컨텍스트 학습보다 일반화 성능을 개선한다.
Action Items
  • 실시간 사용자 피드백을 하이퍼네트워크에 입력해 추천 시스템의 모델 가중치를 즉시 조정함으로써 응답 지연을 감소시킨다.
  • 센서 스트림을 이용해 엣지 디바이스에서 하이퍼네트워크가 가중치를 지속적으로 재생성하도록 하여 개인화 정확도를 높이고 데이터 전송을 최소화한다.
  • 스트리밍 금융 데이터로 베이지안 신념을 업데이트해 LLM이 최신 시장 상황을 반영한 텍스트를 생성하도록 하여 예측 및 보고서 작성 품질을 향상시킨다.
