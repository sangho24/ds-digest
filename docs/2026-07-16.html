Q1. LLM 비판자들이 주로 지적하는 핵심 문제는 무엇인가?
A) 과도한 컴퓨팅 자원 소비
B) 데이터 편향성
C) 모델 해석 불가능성

LLM은 특정 도메인에서 훈련된 모델이 다른 도메인에서 일반화 실패하는 문제가 있으며, 이는 실제 업무 적용 시 한계로 작용합니다.

A) 모든 비즈니스 로직을 LLM으로 대체
B) LLM과 전통적 모델의 하이브리드 접근
C) LLM을 단순 텍스트 생성 도구로 제한
D) LLM 훈련 데이터 확보에 집중
정답 보기
✓ B) LLM과 전통적 모델의 하이브리드 접근
저자는 LLM의 강점을 보완하기 위해 전통적 데이터 과학 기법과의 혼합 모델을 제안하며, 이는 MLOps 구현 시 유연한 솔루션을 제공합니다.
