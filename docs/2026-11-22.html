TideCache: Efficient Hybrid LLM Serving with Transparent Cache Management and Layer-Wise Streaming

GPU 메모리 효율적 관리로 LLM 서빙 속도와 비용을 크게 낮춤

배경과 위치
대규모 LLM을 CPU‑GPU 슈퍼칩에서 서빙할 때, 글로벌 어텐션과 bounded‑state 레이어가 서로 다른 캐시 요구를 갖고 메모리 병목이 발생한다. 기존 연구는 전체 캐시를 GPU에 고정하거나 단순 프리패칭만 적용해 효율이 제한적이었다. TideCache는 투명 캐시 풀과 레이어‑와이어 스트리밍을 결합해 HBM 사용을 동적으로 최적화함으로써 기존 SGLang+HiCache 대비 지연 감소와 처리량 향상을 보여준다.
실행가능성 7
깊이 6
  • · Transparent Cache Pool은 물리 페이지를 재배치하면서 가상 주소를 고정해 캐시 레이아웃과 백엔드 인터페이스를 유지한다.
  • · Cache Streamer는 bounded‑state 레이어의 계산 구간을 활용해 다음 global‑attention 레이어 프리픽스를 미리 GPU 슬롯에 채워 GPU 체류 시간을 줄이고 연산과 전송을 겹친다.
  • · Request Scheduler는 요청 크기와 큐 상태에 따라 resident와 streamed 실행을 선택하고 용량을 동적으로 조정해 전체 P50 토큰 지연을 20‑59% 감소시킨다.
Action Items

  • Cache Streamer의 레이어‑와이어 프리패칭 방식을 비디오 트랜스코딩 파이프라인에 적용해 다음 프레임 그룹을 미리 GPU에 로드해 처리 지연을 줄인다.
  • Request Scheduler의 resident/streamed 선택 로직을 데이터베이스 GPU 가속 엔진에 도입해 대규모 쿼리 중 메모리 집약적인 서브쿼리를 스트리밍 실행으로 전환, 전체 응답 시간을 개선한다.

  • · 포켓몬 팀 빌딩은 10^218 이상의 경우의 수를 가지며, 이는 체스(≈10^50)보다 훨씬 방대하다
  • · 팀 빌딩은 2단계 최적화(2-step Optimization)로 평가되며, 제한된 대전 피드백으로 개선이 어려워 AI 학습에 큰 제약이 된다

Action Items

  • 조합 최적화의 경우의 수 폭발을 고려해 하이퍼파라미터 탐색 시 탐색 공간을 계층적 프루닝으로 축소한다
  • 불완전 정보 모델링을 이용해 전자상거래 가격 책정에서 구매자 정보 비대칭을 시뮬레이션하고 가격 전략을 개선한다
