GenRec: Towards LLM-Native Recommendation at Netflix

핵심 포인트
· GenRec은 사용자 이력·아이템 메타데이터를 자연어 프롬프트로 변환해 LLM에 입력한다.
· Netflix 전용 데이터와 목표로 LLM을 사후 학습하고, 카탈로그 인식 스코어링 헤드를 추가한다.
· 대규모 A/B 테스트에서 기존 랭커보다 적은 라벨 데이터로 통계적으로 유의한 개선을 달성했다.
적용 아이디어
💡 사용자 로그와 아이템 메타데이터를 자연어 형태로 변환해 LLM 기반 랭커에 입력하는 컨텍스트 엔지니어링 파이프라인을 구축한다.
💡 vLLM의 prefill‑only 모드로 전체 카탈로그 아이템에 대한 점수를 효율적으로 계산하도록 서빙 스택을 설계한다.

LLM은 똑똑한데, 왜 우리 회사 일은 모를까

사내 지식 통합·검증으로 LLM 활용 신뢰성 확보

LLMTopicTossidempotency key검색
원본 보기 →
핵심 포인트
· LLM만으로는 사내 정책·코드·미팅 로그 등 분산된 정보를 종합해 답변할 수 없다
· 일반 검색은 최신성·권위·일관성을 판단하지 못해 신뢰 가능한 컨텍스트 제공에 한계가 있다
· ‘Topic’ 시스템은 문서·코드·메신저 데이터를 추출·연결·신뢰 관리하여 LLM과 인간이 함께 사용할 수 있게 만든다
적용 아이디어
💡 문서·코드·미팅 로그를 자동 추출해 메타데이터와 함께 지식 그래프에 저장하고 LLM 질의 시 최신·권위 있는 정보를 우선 반환하도록 파이프라인 구축
💡 답변 생성 전 문서와 실제 코드 구현을 교차 검증하는 검증 레이어를 도입해 일관성 없는 정책 정보를 걸러내는 시스템 설계
