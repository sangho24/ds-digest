Spectral and Subspace Dynamics of LoRA in Supervised Fine-Tuning and Reinforcement Learning

LoRA 단계별 스펙트럼·서브스페이스 차이로 성능 향상

배경과 위치
LoRA는 SFT와 RL에서 널리 쓰이지만 두 단계의 파라미터 업데이트가 어떻게 다르게 진행되는지는 미지였다. 본 논문은 수학 추론 과제에서 LoRA 업데이트의 특잇값 스펙트럼과 서브스페이스 변화를 추적해, 그룹 평균 베이스라인 차감이 스펙트럼 집중과 서브스페이스 회전을 가속한다는 메커니즘을 밝힌다. 이를 바탕으로 SFT와 RL에 각각 최적화된 LoRA 조정 방식을 제안해 기존 방법보다 성능 향상을 입증한다.
실행가능성 7
깊이 7
  • · RL에서는 모든 학습률에서 특잇값 스펙트럼이 집중되고, SFT에서는 중간 학습률에서 스펙트럼이 확장된다.
  • · 그룹 평균 베이스라인 차감이 스펙트럼 집중과 서브스페이스 회전 가속의 원인으로 확인되었다.
  • · SFT에는 전체 업데이트 스펙트럼을 평탄화하고, RL에는 현재 LoRA 증분 스팬 외부를 평탄화하는 맞춤형 전략이 성능을 최고 수준으로 끌어올렸다.

  • 지속 학습에서 새로운 작업에 대한 LoRA 업데이트가 기존 증분 스팬 외부의 스펙트럼을 평탄화하도록 설계해, 이전 작업의 서브스페이스와 충돌을 최소화한다.
  • 대규모 언어 모델 사전학습 중 LoRA 업데이트의 특잇값 스펙트럼을 실시간 모니터링해, 학습률이 과도하게 낮거나 높을 때를 자동 감지한다.

StrataFlux: Memory-Hierarchy-Native Low-Bit LLM Inference

GPU 메모리 절약하면서 저비트 LLM 정확도 회복

배경과 위치
양자화는 메모리·대역폭을 절감하지만 정확도 저하와 고정밀 데이터 오프로드 시 생성 지연을 초래한다. 기존 연구는 정확도와 속도 사이의 트레이드오프를 해결하지 못했다. StrataFlux는 정밀도 스트리밍과 메모리 계층 공동 설계를 통해 GPU 메모리 한계를 넘어선 정확도 향상을 제시한다.
실행가능성 7
깊이 7
  • · StrataFlux는 저비트 가중치·KV 캐시 양자화로 손실된 정확도를 회복하면서 메모리·속도 이점을 유지한다.
  • · 호스트 RAM·SSD를 활용한 선택적 정밀도 스트리밍으로 전송량을 줄이고 연산과 겹쳐 전달하며, 동일 정밀도를 여러 디코딩 단계에 재사용한다.
  • · 실험에서 2비트 Llama‑3.1‑8B는 퍼플렉시티를 9.46→8.40으로 낮추고 95.4% 처리량을 유지했으며, 2비트 가중치·KV로 Qwen3‑8B 정확도를 11%→47.1%로 향상시켰다.
Action Items
  • 추천 시스템에서 임베딩 캐시를 SSD에 저장하고 필요 시 선택적으로 스트리밍해 GPU 메모리 사용을 최소화하면서 랭킹 정확도를 높인다.
  • Diffusion 모델 샘플링 시 고정밀 라티스 업데이트를 CPU 메모리에서 스트리밍해 VRAM 부담을 줄이고 샘플 품질을 유지한다.
  • 실시간 영상 분석에서 고해상도 패치만 SSD에서 선택적으로 스트리밍해 객체 탐지 지연을 감소시킨다.
