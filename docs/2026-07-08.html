퀴즈
Q1. HTTP 프로토콜의 무상태성은 다음 중 어떤 문제를 유발할 수 있는가?
A) 서버 메모리 과부하
B) 사용자 인증 불가
C) 모델 학습 속도 저하
D) 데이터 샘플링 오류
정답 보기
✓ B) 사용자 인증 불가
HTTP는 연결이 끊기면 상태를 유지하지 않기 때문에, 사용자가 로그인 상태를 유지하기 위해 별도의 인증 메커니즘이 필요합니다.
Q2. JWT 토큰 방식의 가장 큰 장점은 무엇인가?
A) 서버 측 세션 저장소 필요 없음
B) 토큰 생성 속도가 빠름
C) 암호화 강도가 높음
D) 쿠키 사용이 불필요함
정답 보기
✓ A) 서버 측 세션 저장소 필요 없음
JWT는 토큰 자체에 인증 정보를 포함하므로 서버가 세션을 저장할 필요가 없어 확장성이 뛰어납니다.
