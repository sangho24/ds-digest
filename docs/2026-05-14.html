퀴즈
Q1. AI 조직에서 TPM 역할 재정의가 필요한 주요 이유는?
A) A. 코드 리뷰 효율화
B) B. 팀 간 의존성 복잡성 증가
C) C. 개발자 생산성 측정
D) D. 클라우드 비용 절감
정답 보기
✓ B) B. 팀 간 의존성 복잡성 증가
본문에서 AI 도입으로 팀 간 의존성이 복잡해지고 회색지대가 증가해 기존 역할 정의로는 부족하다고 설명했습니다.
Q2. TPM이 단순 조율자 역할을 넘어선 핵심 문제는?
A) A. 일정표 최적화
B) B. 정의되지 않은 문제의 소유권 설정
C) C. 문서 자동화
D) D. 코드 리팩토링
정답 보기
✓ B) B. 정의되지 않은 문제의 소유권 설정
문서에 명시된 문제 외에도 소유권이 명확하지 않은 문제들이 조직에서 발생하며 이는 TPM이 해결해야 할 핵심 과제입니다.

💡 CodeRabbit 대신 DS 팀의 모델 변경 요약을 자동화해 PR description에 삽입 (예: 'LightGBM → CatBoost 교체로 추론 속도 30% 향상')
퀴즈
Q1. Stage 1의 핵심 목적은 무엇인가?
A) LLM 모델 훈련
B) PR 데이터 자산화
C) A/B 테스트 결과 요약
D) 사용자 피드백 분석
정답 보기
✓ B) PR 데이터 자산화
Stage 1은 Notion DB에 PR/배포 내역을 자산화해 LLM 입력으로 활용하는 기반을 만드는 단계입니다.
Q2. 왜 변경 코드(diff) 대신 PR description을 사용했나?
A) 모델 성능 향상
B) 토큰 비용 절감
C) 코드 보안 강화
D) 배포 속도 향상
정답 보기
✓ B) 토큰 비용 절감
diff를 사용하면 토큰 비용이 증가하고, 이미 PR description에 요약된 의미를 무시하게 되기 때문입니다.
