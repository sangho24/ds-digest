Q1. LLM에서 발생하는 'data leakage' 문제를 가장 효과적으로 방지하는 방법은?
A) 훈련 데이터 샘플링 시 시간 기반 스플릿
B) 모델 가중치 정규화 적용
C) 프롬프트 템플릿 복잡도 제한
D) 배치 사이즈 최적화
정답 보기
✓ A) 훈련 데이터 샘플링 시 시간 기반 스플릿
시간 기반 스플릿은 훈련/테스트 데이터의 시간적 순서를 보장해 미래 데이터 유출을 방지합니다.
Q2. LLM 모델의 'hallucination' 문제를 감지하기 위한 모니터링 지표는?
A) BLEU 점수
B) Perplexity
C) Answer Relevance Score
D) Training Loss
정답 보기
✓ C) Answer Relevance Score
Answer Relevance Score는 모델 응답과 입력 질문 간의 관련성을 측정해 hallucination을 객관화할 수 있습니다.

Q1. LLM들이 동일 사실에 대해 다른 응답을 할 때 주요 문제는?
A) A. 추론 속도 저하
B) B. 사실 신뢰도 저하
C) C. GPU 사용 증가
D) D. 사용자 인터페이스 복잡도 증가

✓ B) B. 사실 신뢰도 저하
LLM의 일관성 없는 사실 인식은 모델 신뢰도와 사용 결정에 직접적인 영향을 미칩니다.
Q2. 이 현상 해결을 위해 가장 효과적인 접근 방식은?
A) A. 더 큰 모델 훈련
B) B. 앙상블 + 외부 검증
C) C. 사용자 피드백 수집
D) D. 텍스트 길이 제한
정답 보기
✓ B) B. 앙상블 + 외부 검증
다중 모델의 결과 비교와 외부 사실 검증을 결합하는 것이 가장 직접적인 해결책입니다.

핵심 포인트
· DTO는 도메인 로직과 데이터 전달 계층 분리의 핵심 패턴
· 복잡한 시스템에서 데이터 일관성과 유지보수성 향상
· API 응답/요청 데이터 구조 명확화를 통한 협업 효율성 증대
적용 아이디어
💡 MLOps 파이프라인에서 raw data와 feature data를 분리하는 DTO 구조 설계
💡 모델 서빙 시 API Gateway와 ML 서버 간 데이터 전달을 위한 타입 안전한 DTO 스펙 정의
퀴즈
Q1. DTO의 주요 목적은 무엇인가?
A) 모델 성능 최적화
B) 데이터 전달 계층과 도메인 로직 분리
C) GPU 리소스 절약
D) A/B 테스트 실험 설계
정답 보기
✓ B) 데이터 전달 계층과 도메인 로직 분리
DTO는 데이터 전달 계층과 비즈니스 로직을 분리하여 시스템의 유지보수성과 확장성을 높이는 설계 패턴입니다.
Q2. DTO를 사용하지 않으면 발생할 수 있는 문제는?
A) 모델 학습 시간 증가
B) 데이터 일관성 저하
C) GPU 메모리 누수
D) A/B 테스트 통계 유의성 감소
정답 보기
✓ B) 데이터 일관성 저하
DTO 미사용 시 데이터 전달 과정에서의 일관성 문제로 인해 시스템 전체의 예측 가능성이 떨어집니다.
