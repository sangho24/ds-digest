REGER: Modeling inter-item Relations with Semantic IDs for Generative Recommendation

아이템 간 관계를 반영한 추천 모델로 성능 향상

배경과 위치
개인화 추천에서는 아이템 간 의미·협업 관계를 동시에 학습해야 하지만 기존 생성적 추천은 무작위 SID 임베딩으로 의미 관계를 상속하지 못하고, 협업 관계는 토큰‑레벨 어텐션에 묻힌다. REGER는 의미 사전학습과 SID 경계에 맞춘 전·지역 어텐션, 그리고 SID 접두사 트리를 이용한 계층적 선호 분해를 도입해 이러한 한계를 극복하고, 실험에서 기존 GR 베이스라인보다 일관된 성능 향상을 보인다.
실행가능성 7
깊이 7
  • · REGER는 의미 사전학습과 SID 생성 과정을 통해 아이템 간 의미 유사성을 명시적으로 학습한다.
  • · SID 경계에 맞춘 전역·지역 어텐션을 결합해 히스토리 컨텍스트와 인접 아이템 전이 정보를 효과적으로 포착한다.
  • · 계층적 선호 분해 이론을 제시해 협업 선호 분포를 정확히 팩터화하고, KL 발산을 접두사 조건부 형태로 분해한다.
Action Items
  • 생성적 의미 검색 사전학습을 전자상거래 상품 검색에 적용해 카테고리별 의미 ID를 생성, 검색 정확도와 재랭킹 효율을 높인다.
  • SID 접두사 트리를 활용한 계층적 선호 분해를 음악 플레이리스트 자동 생성에 적용해 사용자의 장르·분위기 선호를 단계별로 모델링, 다양성과 만족도를 향상시킨다.
  • 전역·지역 어텐션을 세션 기반 광고 클릭 예측에 도입해 장기 행동 히스토리와 즉시 클릭 전이를 동시에 고려, 예측 정확도와 광고 효율을 개선한다.
