The Dice Roll Method: A Standardized Protocol for Repeated-Query Auditing of Large Language Model Brand Recommendations

LLM 브랜드 추천의 변동성을 통계적으로 검증하는 표준 프로토콜 제공

배경과 위치
LLM 브랜드 추천의 불안정성을 정량화할 표준 절차가 부재하던 상황에서, 반복 질의와 변동성 분해를 통합한 Dice Roll Method를 제안한다. 기존 연구는 단일 지표나 임의 반복에 머물렀지만, 이 논문은 통계 모델과 일반화 이론을 도입해 반복 횟수와 신뢰도 기준을 체계화한다. 따라서 LLM 출력 안정성 평가 흐름에서 방법론적 전환점으로 작용한다.
실행가능성 7
깊이 8
  • · Dice Roll Method는 반복 질의 감사에 대한 반복 횟수와 일반화 계수를 기반으로 탐색·확인·엄격 3단계 가이드라인을 제시한다.
  • · 전체 변동을 샘플링·프롬프트·런투런·모델버전 네 요소로 분해하고, 음이항 혼합모델·Cliff's delta·부트스트랩·일반화 이론을 결합한다.
  • · 외부 검증에서 신뢰도 예측은 대부분 재현되었지만 고정된 반복 횟수 가이드라인은 일반화되지 않아 파일럿‑후‑해결 전략을 권장한다.
Action Items
  • Dice Roll Method의 반복 횟수 가이드라인을 감성 분석 모델의 프롬프트 안정성 평가에 적용해 최소 실험 설계 비용을 절감한다.
  • 음이항 혼합모델 기반 변동성 분해를 추천 시스템의 순위 변동 원인 분석에 활용해 데이터·알고리즘·시스템 요인을 구분한다.
  • 파일럿‑후‑해결 단계 설정을 코드 생성 LLM의 품질 검증 파이프라인에 도입해 초기 파일럿 결과에 따라 반복 횟수를 동적으로 조정한다.
