WISE: An Agentic Framework for Whole-page Multimodal Search Experience Attribution

검색 서비스 품질 원인 추적 방법을 제시해 DS 현업의 문제 해결을 돕는다

배경과 위치
산업 검색 서비스에서 운영 단계의 품질 모니터링은 결과의 정확성만을 확인해 왔지만, 원인 추적이 부족했다. 기존 연구는 모델 최적화에 초점을 맞추었으며, 시스템 전반의 진단 체계는 부재했다. 본 논문은 SQD라는 새로운 과제를 정의하고, 에이전트 기반 WISE 프레임워크로 원인 추적을 자동화함으로써 검색 품질 진단 흐름에 혁신을 제공한다.
실행가능성 7
깊이 6
  • · System Quality Diagnosis(SQD) 개념을 도입해 결과 품질을 원인까지 진단한다
  • · WISE 프레임워크와 ReTrace, AHPO 기법으로 에이전트 기반 진단 정확도를 크게 향상시킨다
  • · 실제 멀티모달 검색 벤치마크(WISE-BENCH)에서 75.20% 정확도를 달성하고 프로덕션에 적용한다
Action Items
  • ReTrace를 전자상거래 추천 시스템에 적용해 사용자 불만을 개별 모델 단계와 연결, 원인 분석 효율을 높인다
  • AHPO를 온라인 광고 입찰 파이프라인에 도입해 실패 신호 기반 정책을 최적화, 부정확한 입찰을 감소시킨다
  • WISE와 유사한 에이전트 진단 구조를 자율주행 차량의 센서·인식 스택에 적용해 오류 발생 시 원인 모듈을 빠르게 파악한다

Adaptive Harness-Policy Optimization(AHPO)이 에이전트를 개선하는 방식은?
① 무작위 탐색을 사용한다
② 실패 신호를 활용해 하네스와 정책을 동시에 최적화한다
③ 모델 크기를 확대한다
④ 지연 시간을 최소화한다
② 실패 신호를 활용해 하네스와 정책을 동시에 최적화한다

에이전트 워크로드를 저비용·고성능 S3 기반 액터로 대규모 운영 가능

실행가능성 6
깊이 7
  • · Rivet는 S3를 백엔드로 하는 경량 액터를 제공해 인‑메모리 상태와 SQLite 기반 영구 저장소, 대기 시 휴면 기능을 지원하며 SSD 수준 속도를 유지한다.
  • · 액터는 72KB 메모리 사용량과 4.9ms 시작 지연으로 샌드박스(512MB, 1.7s)보다 훨씬 효율적이며 대규모 에이전트 워크로드에 적합하다.
  • · 기존 FoundationDB에서 S3로 전환해 저장 비용을 10배 절감하면서도 성능을 유지, 대용량 세션 기록·아티팩트 저장에 최적화했다.
Action Items
  • 대규모 모델 학습 시 체크포인트를 S3에 직접 저장하고 로컬 캐시를 SSD처럼 사용해 비용을 크게 낮춘다.
  • 데이터 전처리 파이프라인을 액터 기반으로 설계해 bursty 입력에 대해 메모리 효율적으로 처리하고 필요 시 휴면 상태로 전환한다.
  • IoT 디바이스에서 SQLite를 S3와 연동해 로컬에서 빠르게 조회하고, 오래된 데이터는 저비용 S3에 영구 보관한다.

① 레이터시가 감소한다
