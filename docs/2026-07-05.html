퀴즈
Q1. SOP(Same-Origin Policy)는 어떤 제한을 주입가요?
A) A. 데이터베이스 접근 제한
B) B. 도메인 간 자원 요청 제한
C) C. CPU 사용량 제한
D) D. 모델 파라미터 크기 제한
정답 보기
✓ B) B. 도메인 간 자원 요청 제한
SOP는 동일 도메인 외부 자원 요청을 차단하여 보안을 강화합니다.
Q2. CORS 오류 해결 시 사용되는 HTTP 헤더는?
A) A. Content-Type
B) B. Cache-Control
C) C. Access-Control-Allow-Origin
D) D. User-Agent
정답 보기
✓ C) C. Access-Control-Allow-Origin
Access-Control-Allow-Origin 헤더로 원본 허용 범위를 설정합니다.
