핵심 포인트
· 데이터 생명주기는 생성·가공·활용·보관·폐기의 단계로 구성된다
· 소프트 딜리트는 화면에서 사라지지만 스토리지를 차지해 유령 데이터가 된다
· 배치, TTL, 파티셔닝을 활용해 정해진 기간 후 데이터를 실제 삭제한다

💡 TTL 컬럼을 활용해 세션 토큰·인증 코드를 자동 만료시키고 별도 삭제 로직을 제거하여 인프라 비용 절감

Q1. 어떤 삭제 방식은 별도 삭제 로직 없이 데이터가 지정된 기간이 지나면 자동으로 제거되는가?
A) Batch
B) TTL
C) Partitioning
D) Soft Delete
정답 보기
✓ B) TTL

Q2. 자주 사용하는 데이터의 복구 요청이 급격히 감소하는 시점은 대략 얼마인가?
A) 1일
B) 7일

D) 90일
정답 보기
✓ B) 7일
