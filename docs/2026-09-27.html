Temporal Gradient Inversion for Private Trajectory Reconstruction in Embodied Reinforcement Learning

시계열 그래디언트가 행동을 노출함을 경고

배경과 위치
분산된 embodied RL에서 원시 센서 데이터를 디바이스에 보관하고 정책 그래디언트만 전송하는 방식은 프라이버시를 제공한다고 여겨졌지만, 기존 단일 프레임 공격만 고려했다. 본 논문은 시간적 그래디언트의 상관성을 이용해 연속 관측‑행동 궤적을 복원하는 TRACE 공격을 제안하며, 기존 방법보다 빠르고 정확하게 프라이버시 침해 가능성을 보여준다.
실행가능성 7
깊이 6
  • · TRACE는 연속 정책 그래디언트의 시간적 상관성과 정책 헤드 그래디언트 구조를 이용해 관측‑행동 궤적을 자동회귀적으로 복원한다.
  • · 복원 품질은 18.8 dB PSNR, 행동 복원은 거의 완벽하며 프레임당 3‑4.5 ms로 기존 방법보다 빠르고 정확하다.
  • · 실험은 순환, 잔차, 경량 트랜스포머 등 다양한 아키텍처에 적용 가능함을 보여주며, 시퀀스‑인식 프라이버시 방어가 필요함을 시사한다.
Action Items
  • 연속 그래디언트의 시간적 상관성을 활용해 연합 학습 중 언어 모델 업데이트에서 개인 텍스트 유출을 탐지한다.
  • 정책 헤드 그래디언트 구조의 폐쇄형 복원을 이용해 온‑디바이스 음성 인식 모델의 사용자 입력을 복원, 감사 도구로 활용한다.
  • TRACE의 amortized inversion 방식을 시계열 예측 모델(예: 주가 예측) 업데이트에 적용해 과거 민감 데이터가 얼마나 추론될 수 있는지 평가한다.
