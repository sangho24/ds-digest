MedGraph: Maintaining Patient State with Graph Memory for Long-Term Medical Dialogue

환자 상태를 그래프 메모리로 정확히 추적해 의료 대화 품질 향상

배경과 위치
환자 방문 간 상태를 유지해야 하는 LLM 기반 의료 비서의 메모리 한계(구식 정보, 타인 정보 혼합, 안전 사실 누락)를 해결하고자 기존 메모리 시스템의 오류를 분석했다. MedGraph는 사실을 시계열 그래프와 체인 구조로 조직해 정확한 조회를 가능하게 함으로써 장기 의료 대화 연구 흐름에서 메모리 관리와 그래프 기반 지식 표현을 결합한 새로운 접근을 제시한다.
실행가능성 7
깊이 6
  • · MedGraph는 세션별 날짜가 있는 사실을 추출하고 사람별로 속성화한 뒤 약물·진단·측정 기록을 체인으로 연결해 이전 상태를 보존한다
  • · 조회 단계에서 환자 체인을 단위로 순위 매기고 질문 시점에 해당 체인을 읽으며 원본 대화와 안전 사실 프로필을 추가한다
  • · MedMemoryBench에서 MedGraph는 GPT와 Qwen 백본 모두 최고 정확도를 기록해 기존 5개 베이스라인보다 약 10점 이상 향상시켰다
Action Items
  • 고객 지원 챗봇에 그래프 메모리를 도입해 고객별 이슈와 해결 과정을 체인으로 연결하면 대화 연속성과 최신 정보 제공이 개선된다
  • 금융 자문 LLM에 체인 기반 그래프 메모리를 적용해 포트폴리오 변동과 규제 조건을 시간 순서대로 추적하면 최신 상황을 반영한 조언이 가능해진다
  • 산업 IoT 모니터링 시스템에 안전 사실 프로필을 추가해 센서 데이터와 유지보수 기록을 그래프로 연결하면 안전 제약을 고려한 알림 및 의사결정이 강화된다

Memorilla: Latent Semantic Memory for LLMs

LLM에 16 토큰 메모리로 성능·학습 지속성 크게 향상

배경과 위치
대규모 언어 모델은 파라미터 외 정보를 활용하려면 컨텍스트 창에 메모리를 삽입해야 하지만, 관련 정보를 효율히 선택·압축하는 것이 어려웠다. 기존 RAG·메모리 시스템은 전체 문서를 그대로 넣거나 복잡한 검색 파이프라인을 사용했다. Memorilla는 문서를 한 번 임베딩하고, 질의에 따라 16개의 메모리 토큰에 정보를 압축해 제공함으로써, 제한된 컨텍스트에서도 성능을 높이고 지속 학습을 가능하게 한다.
실행가능성 6
깊이 6
  • · Memorilla는 전체 문서 컬렉션을 질의 의존적인 고정 수의 메모리 토큰으로 압축해 제공한다
  • · 16개의 메모리 토큰만으로 FactKG에서 84.33% 정확도를 달성, 전체 컨텍스트 대비 108배 적은 토큰 사용
  • · TextWorld 환경에서 에이전트의 성공률을 18.6%→24.2%로 향상시켜 지속 학습을 지원한다
Action Items
  • 사용자 행동 로그를 질의 의존적인 메모리 토큰으로 압축해 실시간 추천 모델의 입력으로 활용하면, 긴 히스토리를 짧은 컨텍스트로 전달해 응답 속도를 개선한다
  • 이미지 특징 집합을 메모리 토큰으로 변환해 고정 길이 입력으로 제공하면, 동결된 비전‑언어 모델이 멀티모달 검색에서 긴 이미지 컬렉션을 효율적으로 활용할 수 있다
  • 시계열 데이터의 장기 이력을 메모리 토큰으로 요약해 LLM 기반 예측 모델에 전달하면, 컨텍스트 길이 제한 없이 과거 트렌드를 반영한 예측이 가능해진다

깊이 6

  • · Sparse Autoencoders와 같은 희소 사전학습 방법으로 모드를 복원하며, 기존 희소 기법보다 우수함을 보인다.
  • · 복원된 모드에 자연어 라벨을 붙여 텍스트 학습 없이도 제로샷 청중 검색과 특성화가 가능하다.

  • 클릭스트림 세션 임베딩에 희소 딕셔너리 학습을 사용해 세션 패턴을 모드로 분해하고, 이상 행동 탐지에 활용한다.
  • 직원 성과 임베딩에 제로샷 자연어 라벨링을 적용해 행동 유형을 자동 명명하고 인재 관리 정책을 맞춤화한다.
