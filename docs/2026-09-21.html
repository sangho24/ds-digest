Large Language Models as Falsifiers for Cyber-Physical Systems

LLM으로 CPS 검증, 시뮬 비용 절감

배경과 위치
CPS의 형식적 규격 검증은 STL 기반 강건성 최적화로 접근해 왔으며, 기존에는 블랙박스 탐색·베이지안 등 수치 최적화에 의존했다. 본 논문은 LLM을 프롬프트 기반 최적화기로 활용해 의미 정보를 결합, 샘플 효율성을 크게 개선한 연구이며, LLM 활용 검증 흐름의 새로운 단계로 자리한다.
실행가능성 6
깊이 5
  • · LLM-Falsifier는 LLM을 이용해 STL 강건성 지수를 최소화함으로써 CPS 규격을 위반하는 사례를 찾는다.
  • · 자연어 입력·출력 이름, 궤적, 최소 강건성 시점 등 의미 정보를 LLM에 제공해 샘플 효율성을 높인다.
  • · ARCH‑COMP 벤치마크에서 21개 규격 중 14개에서 기존 도구보다 평균 시뮬레이션 수가 적게 소요되었다.
Action Items

  • 데이터 파이프라인의 컬럼명·샘플 데이터를 LLM에 제공해 하이퍼파라미터 탐색을 효율화한다.
  • API 계약 위반 메트릭을 최소화하도록 LLM에게 엔드포인트명·예시 페이로드를 입력해 테스트 케이스 자동 생성한다.
