Variants of Beam Search for DiskANN

대규모 ANN 검색 Beam Search 효율 크게 개선

배경과 위치
대규모 근사 최근접 이웃 검색에서 그래프 기반 인덱스의 탐색 효율이 한계에 봉착했다. 기존에는 α‑reachable 그래프에 대해 (α+1)/(α-1) 근사와 ABS가 2/γ 근사를 제공했지만 보장되지 않았다. 본 논문은 두 접근을 통합해 일반적인 근사 한계를 제시하고, 실제 DiskANN 구축 그래프에 적용 가능한 Beam predictor를 제안한다.
실행가능성 7
깊이 6
  • · ABS와 γ 파라미터를 결합하면 α‑reachable 그래프에서 근사 비율 (α+1)/(α(γ+1)-1)을 달성한다.
  • · 정렬된 α‑reachable 그래프(ℓ2)에서는 max(α/(α(γ+1)-1), (α²+1)/(α²(γ+1)-1))라는 더 강한 경계가 얻어진다.
  • · Beam predictor는 SSD‑상 인덱스에서 CBS 대비 평균 지연시간을 최대 29.6% 감소시키고, 거리 계산도 1‑24% 절감한다.
Action Items
  • Beam predictor의 특성 기반 적응형 빔 크기 선택을 추천 시스템의 실시간 유사 아이템 검색에 적용해 응답 지연을 줄인다.
  • ABS의 γ 완화 파라미터를 네트워크 라우팅 그래프에 도입해 경로 탐색 비용을 조절하고, 최단 경로 근사 정확도를 제어한다.
  • 정렬된 α‑reachable 그래프의 강화된 근사 경계를 이용해 고차원 이미지 특징 검색 엔진에서 거리 계산량을 최소화한다.

깊이 6

  • · 사용자는 서버 키 또는 개인 API 키를 이용해 무료 혹은 유료 시프트를 실행하고, 샌드박스와 레거시 환경을 선택할 수 있다.

Action Items

  • 서브에이전트 구조를 활용해 자동 피처 엔지니어링 파이프라인을 구축, 매니저 LLM이 후보 피처를 생성·평가하도록 하여 모델 성능 향상을 가속화한다.
  • 모델 모니터링 시스템에 서브에이전트를 두어 드리프트 보고서를 작성하게 하고, 매니저 LLM이 리뷰와 알림을 자동으로 제공해 운영 효율성을 높인다.
