핵심 포인트
· Prediction and compression are mathematically equivalent per information theory.
· LLM pre‑training objective can be viewed as building an optimal text compressor.
· Shannon's noiseless coding theorem provides insight into compression limits.
적용 아이디어
💡 Evaluate LLM pre‑training data redundancy using Shannon entropy estimates to prune unnecessary tokens.
💡 Treat cross‑entropy loss as a direct compression metric, guiding model architecture and data selection for more efficient training.

B) Cross‑entropy loss
C) Hinge loss
D) KL divergence
정답 보기
✓ B) Cross‑entropy loss
The transcript states that the pre‑training objective is usually described as next‑token prediction using cross‑entropy loss, and that cross‑entropy originates from information theory where prediction and compression are equivalent.
