Q1. 그래프 DB 확장성 문제를 해결하기 위해 HelixDB가 채택한 주요 전략은?
A) 데이터 중복 복제
B) S3 객체 저장소 활용
C) 관계형 DB 셰딩
D) 인메모리 캐싱
정답 보기
✓ B) S3 객체 저장소 활용
HelixDB는 S3 객체 저장소를 기반으로 데이터를 저장하고 필요 시만 로드하는 방식으로 확장성을 해결했습니다.
Q2. HelixDB가 일반적인 그래프 DB 확장 방식과 다른 점은?
A) 분산 노드 간 데이터 복제
B) 관계형 DB 셰딩 방식 적용
C) 엣지 기반 분할 대신 객체 저장소 활용
D) GPU 기반 인메모리 처리
정답 보기
✓ C) 엣지 기반 분할 대신 객체 저장소 활용
기존 그래프 DB는 셰딩이나 복제로 확장하지만, HelixDB는 객체 저장소(S3)를 활용해 그래프의 물리적 분할 없이 확장합니다.
