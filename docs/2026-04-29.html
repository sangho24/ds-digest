· Event Sensor를 통해 메시지 기반 자율 실행 파이프라인 구축
· Omni-Evaluator로 다중 엔진/벤치마크 통합 평가 시스템 구현
· 클라우드 간 호환성 확보를 위한 느슨한 결합 아키텍처 설계
적용 아이디어

💡 Omni-Evaluator를 활용한 실시간 모델 성능 비교 대시보드 개발 (MLflow + Prometheus 연동 기반 A/B 테스트 자동화)

Q1. Event-driven MLOps의 핵심 구성 요소는 무엇인가요?
A) Kubeflow 파이프라인
B) Event Sensor
C) MLflow Tracking
D) Docker Container

✓ B) Event Sensor
Event Sensor는 Typed Message를 감지해 자율 실행을 트리거하는 핵심 컴포넌트로, 전통적 파이프라인 오케스트레이터 대체

A) 모델 배포 자동화
B) 다중 엔진/벤치마크 통합 평가

정답 보기
✓ B) 다중 엔진/벤치마크 통합 평가
Omni-Evaluator는 다양한 ML 엔진과 평가 지표를 통합해 일관된 모델 평가 프레임워크를 제공
