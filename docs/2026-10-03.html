KaliBench: A Fine-Grained Benchmark for Cybersecurity Tool Use on Kali Linux with Runtime-Free Verifiable Rewards

CLI 기반 보안 도구 자동화 평가로 모델 실용성 판단

배경과 위치
LLM을 사이버 보안 워크플로에 적용하려면 정확한 CLI 명령 생성이 필수인데, 기존 평가는 지식 수준이나 엔드‑투‑엔드 에이전트만 평가했다. 본 연구는 자연어‑CLI 변환을 정량화하고, 검증 가능한 보상을 제공해 보안 도구 사용 능력 평가와 모델 튜닝을 동시에 가능하게 하는 새로운 벤치마크 흐름을 제시한다.
실행가능성 7
깊이 6
  • · KaliBench는 8,504개의 질의‑명령 쌍과 1,642개의 도구를 아우르는 정밀 NL‑to‑CLI 벤치마크를 제공한다.
  • · LLM 검증, 샌드박스 실행, 인간 피드백을 결합한 다단계 검증 파이프라인으로 명령의 의미와 실행 가능성을 보장한다.
  • · 오픈‑weight 모델은 42% 이하의 정확도에 머물지만, 지도학습·강화학습으로 8B 모델을 685B MoE 수준으로 끌어올렸다.
Action Items
  • NL‑to‑SQL 생성에 동일한 다단계 검증 파이프라인을 적용해 쿼리 문법 오류를 사전에 차단한다
  • API 호출 자동 생성 시 별칭‑인식 평가와 샌드박스 실행을 도입해 실서비스 적용 안전성을 높인다
  • 데이터 파이프라인 정의(Airflow DAG)에서 런타임‑프리 검증 보상을 활용해 모델이 올바른 작업 흐름을 설계하도록 학습한다
