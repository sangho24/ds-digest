Q2. Pass@k는 무엇을 의미하는가?
A) k번 샘플링 중 최소 하나가 정답일 확률
B) 평균 추론 시간
C) 모델 파라미터 수
D) 학습 데이터 양
정답 보기
✓ A) k번 샘플링 중 최소 하나가 정답일 확률
Pass@k는 k번 시도(샘플링)했을 때 적어도 하나의 정답을 얻을 확률을 나타낸다.

💡 이벤트 유형 가중치 부여 또는 listing view 다운샘플링을 적용해 시퀀스 모델 입력을 최적화한다.
