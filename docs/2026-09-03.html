핵심 포인트
· L-shaped SFT는 가중치 공유를 이용해 서버에서 목표 임베딩으로 직접 손실을 계산해 양방향 통신을 없앱니다.
· one-shot SFT는 클라이언트가 활성화를 한 번만 업로드하고 오프라인 상태에서도 서버가 최적화를 지속하도록 합니다.
· 다양한 엣지 디바이스 실험에서 기존 SFT 대비 통신량과 클라이언트 온라인 시간이 크게 감소함을 입증했습니다.
적용 아이디어
💡 L-shaped SFT를 적용해 엣지 디바이스에서 LLM 파인튜닝 시 통신량을 절감하고 학습 효율을 높인다.
💡 one-shot SFT 방식을 도입해 모바일 클라이언트가 한 번만 활성화를 전송하고 이후 오프라인 상태에서도 서버가 학습을 진행하도록 설계한다.
퀴즈
Q1. L-shaped SFT가 서버에서 손실을 직접 계산할 수 있게 한 핵심 원리는 무엇인가?

✓ A) 가중치 공유(weight tying)
현대 LLM의 가중치 공유 특성을 활용해 서버 측 은닉 활성화를 목표 임베딩과 직접 비교함으로써 클라이언트로부터 출력값을 반환받지 않아도 손실을 계산할 수 있다.

WebLLM: high-performance in-browser LLM inference engine

WebLLMWebGPUOpenAI APIMLC LLMLlama 3
원본 보기 →
핵심 포인트
· WebLLM은 WebGPU 기반 하드웨어 가속을 활용해 브라우저 내에서 대규모 언어 모델 추론을 실시간으로 수행한다.
· OpenAI API와 완전 호환되어 오픈소스 모델을 동일한 엔드포인트와 스트리밍, JSON 모드, 함수 호출 인터페이스로 활용 가능하다.
· 다양한 사전 학습 모델(Llama 3, Phi 3 등)을 WebAssembly와 WebGPU 조합으로 로드하여 클라이언트 측에서 GPU 메모리와 연산을 효율적으로 관리한다.
적용 아이디어
💡 클라이언트 측에서 개인정보가 포함된 텍스트 데이터를 WebLLM으로 전처리·분석하여 서버 전송 없이 실시간 인사이트를 도출한다.
💡 WebLLM의 JSON 모드와 함수 호출 기능을 활용해 웹 기반 데이터 라벨링 인터페이스를 구축하고 라벨링 로직을 브라우저에서 실행한다.

A) WebAssembly
B) WebGL
C) WebGPU
D) Service Workers
정답 보기
✓ C) WebGPU
WebLLM은 WebGPU를 이용해 GPU 수준의 하드웨어 가속을 제공한다.

B) OpenAI API
