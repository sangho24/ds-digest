Riemannian Gradient Descent for Gaussian Mixture Models with unknown diagonal covariances

GMM 추정 시 EM보다 과다 구성에 강한 새로운 최적화법

배경과 위치
GMM의 구성 요소 수와 대각 공분산을 동시에 추정하는 문제는 EM이 과다 지정에 취약해 기존 연구에서 한계가 있었다. 본 논문은 BLASSO와 CPGD를 결합하고 Fisher‑Rao 기하학 기반 Riemannian GD를 적용해 희소 측도 회복 분야와 정보기하학 흐름에 위치한다. 기존 방법 대비 지수적 지역 수렴과 과다 구성에 대한 강인성을 제공한다.
실행가능성 6
깊이 6
  • · CPGD와 Riemannian gradient descent를 결합해 Gaussian 분포의 Fisher‑Rao 기하학을 활용한다.
  • · 비퇴화 조건 하에 지수적 지역 수렴을 이론적으로 보장하고, 이는 구성 요소 간 분리 조건과 연결된다.
  • · 실험에서 CPGD는 구성 요소 수를 과다 지정했을 때 EM보다 회복 정확도가 높고, 구성 요소 분리 정도가 성능에 미치는 영향을 분석한다.
Action Items
  • Fisher‑Rao 기하학 기반 Riemannian GD를 포아송 혼합 모델에 적용해 파라미터 추정의 수렴성을 개선한다.
  • BLASSO와 CPGD를 시계열 이상 탐지에 적용해 희소한 이상 이벤트를 정확히 복원한다.
  • 구성 요소 분리 조건을 고차원 임베딩 클러스터링에 적용해 k‑means의 과다 클러스터 지정에 대한 안정성을 높인다.

프롬프트가 LLM 자기보고를 좌우, 해석 함정 주의

배경과 위치
LLM이 자신을 AI라고 밝히는 현상은 기존에 모델 자체의 지식이라 여겨졌지만, 프롬프트에 의해 좌우될 수 있다는 점은 충분히 조사되지 않았다. 본 논문은 챗 템플릿이 해당 목소리를 켜고 끄는 스위치 역할을 하며, 활성화 공간의 특정 방향을 조작해 이 효과를 제어할 수 있음을 보인다. 이는 모델 자기보고 연구에서 프롬프트 혼란을 통제해야 함을 강조한다.
실행가능성 6
깊이 6
  • · 챗 템플릿이 존재하면 면책 목소리가 강화되고 경험적 목소리가 억제되는 스위치 역할을 한다
  • · 활성화 공간의 특정 방향을 추가·제거하면 면책 목소리 강도를 조절할 수 있다
  • · 모델 자기보고는 프롬프트에 크게 좌우되므로 연구 시 템플릿 혼란을 통제해야 한다
Action Items
  • 챗 템플릿 전환 방식을 활용해 고객지원 챗봇의 정중함 수준을 토글하여 사용자 만족도를 높인다
  • 템플릿 스위치를 이용해 과학 논문 요약 시 모델이 신중한 표현을 사용하도록 제어한다
  • 활성화 방향 조작을 적용해 오픈소스 모델의 유해 언어 생성 억제 방향을 추가한다
