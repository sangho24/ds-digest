Can It Actually Work? Synthesizing Functional CAD Mechanisms

LLM으로 CAD 설계 물리 검증, 성공률↑

배경과 위치
기존 CAD 자동화는 시각적 일치에 머물러 물리적 기능 검증이 어려웠다. 본 논문은 기능 요구를 시뮬레이션 테스트로 변환하고 반복적으로 수정하는 프레임워크와 46가지 메커니즘 벤치마크를 제시해 LLM 기반 설계의 실용성을 한 단계 끌어올린다.
실행가능성 6
깊이 6
  • · LLM이 만든 CAD는 시각적으로는 설득하지만 물리적 기능을 만족하지 못한다
  • · FunCAD-Harness가 추상 요구를 구체적 시뮬레이션 테스트로 변환해 설계 수정에 피드백을 제공한다
  • · FunCADBench(46개 메커니즘) 실험에서 기능 성공률이 기존 시뮬레이션 기반 베이스라인보다 크게 향상된다
Action Items
  • FunCAD-Harness 방식을 로봇 작업 계획에 적용해 고수준 작업 명세를 시뮬레이션 기반 검증 루프로 바꾸면 로봇 행동의 물리적 타당성을 빠르게 개선할 수 있다
  • LLM이 만든 데이터 파이프라인 설계에 추상 요구를 테스트 스위트로 변환하는 벤치마크를 도입하면 설계 단계에서 오류를 자동으로 탐지할 수 있다
  • UI 자동 생성에 FunCAD-Harness의 반복 수정 루프를 적용해 UI 기능 명세를 자동 UI 테스트로 변환하면 LLM이 만든 UI의 사용성 및 기능성을 지속적으로 향상시킬 수 있다
