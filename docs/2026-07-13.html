퀴즈
Q1. 해커톤에서 AI가 가장 탁월하게 수행한 역할은?
A) 전략 수립
B) 리스크 평가
C) 계획 수립
D) 최종 결정
정답 보기
✓ C) 계획 수립
본문에서 '계획(planning)에 강했고, 끝까지 사람의 몫으로 남은 일은 전략(strategy)이었다'고 명시됨
Q2. 사내 인프라 특수성을 대응하기 위해 팀이 채택한 핵심 전략은?
A) 공개 문서만 사용
B) 사내 저장소 연결
C) 기존 프레임워크 고수
D) 외부 클라우드 전환
정답 보기
✓ B) 사내 저장소 연결
사내 코드 저장소, 이슈 트래커, 위키를 MCP로 연결해 AI가 직접 검색하도록 했음
