QF3: Fast Flow RL with Filtered Q-Gradients

오프라인 RL로 흐름 정책을 빠르게 학습·전이 가능해 로봇 개발 효율을 크게 높인다

배경과 위치
기존 데모 기반 흐름 정책은 강화학습으로 개선이 필요했지만 온‑폴리시 방법인 FPO++은 학습 속도가 느렸다. QF3는 오프‑폴리시 흐름 RL의 첫 사례로, 인간형 로봇 보행을 스크래치로 학습하고 하드웨어에 바로 전이하며, 기존 대비 10배 빠른 학습 효율을 제공한다
실행가능성 7
깊이 6
  • · QF3는 흐름 매칭과 필터링된 비평가 기울기를 결합한 온라인 오프라인 RL 알고리즘이다
  • · 비평가 기울기는 재생 버퍼의 행동과 가까운 차원에만 적용해 신뢰성을 확보한다
  • · FPO++ 대비 10배 빠른 학습 속도와 제로샷 하드웨어 전이, ABC‑Sim·Robomimic 파인튜닝 성공을 보여준다
Action Items
  • 필터링된 비평가 기울기 방식을 대규모 언어 모델 파인튜닝에 적용해, 기존 데이터와 유사한 토큰에만 업데이트함으로써 망각을 방지한다
  • 하나‑스텝 정책 예측을 이용해 가치 기울기를 역전파하는 방식을 자율주행 시뮬레이션에 도입해, 위험 상황에서 정책 업데이트의 안정성을 높인다
  • 금융 트레이딩 봇에 흐름 매칭과 필터링된 Q‑그라디언트를 적용해, 과거 거래와 유사한 포지션에만 학습을 집중시켜 변동성에 대한 안정성을 강화한다

  • · 실험에서 복원된 추론을 사용하면 요약만 학습했을 때보다 성능이 크게 향상돼 추론 은폐만으로는 방어가 불가능함을 보여준다
Action Items

  • API 호출 패턴을 모니터링해 적대적 증류 시도를 탐지하고 자동 차단 정책을 적용한다
  • 요약된 최종 예측만 있는 저리소스 도메인에서 Surrogate·Inversion 모델을 활용해 합성된 추론을 생성, 라벨링 비용을 절감한다
