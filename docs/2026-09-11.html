Glyph: A Multi-Strategy Agentic System for Column Description and Sensitivity-Ontology Tagging of Enterprise Data Catalogs

데이터 카탈로그 컬럼 메타데이터 자동화로 관리 부채 감소

배경과 위치
기업 데이터 레이크에서 컬럼 메타데이터 부재가 데이터 검색·거버넌스에 장애가 되는 문제를 해결하기 위해, 기존 단일 모델 기반 컬럼 타입 분류와 정규식 스캐너가 갖는 확장성·정확도 한계를 극복하고자 한다. Glyph는 LLM 에이전트를 그래프 형태로 결합하고, RAG 및 대비 학습 기반 메타데이터 인코더를 병렬로 활용함으로써 최신 멀티에이전트·RAG 연구 흐름에 속하면서도 실서비스 적용을 목표로 하는 엔터프라이즈 데이터 카탈로그 자동화 연구이다.
실행가능성 7
깊이 7
  • · Glyph는 컬럼 설명 생성과 타입 주석을 상태 기반 그래프 상의 협업 LLM 에이전트로 모델링하고, Descriptor 에이전트는 엔터프라이즈 GitHub에서 파이프라인 소스 코드를 실시간으로 가져와 활성 Retrieval‑Augmented Generation을 수행한다.
  • · Tagger는 설명 기반 태거, 라인‑오브‑비즈니스 정규식 태거, 메타데이터 대비 인코더 기반 벡터 DB 태거라는 세 상보적 전략을 병렬 실행하고, Reciprocal Rank Fusion으로 순위를 결합해 NDCG@10을 0.55에서 0.92, MAP@100을 0.19에서 0.90으로 크게 향상시킨다.
  • · 평가에서는 recall‑weighted F2 목표를 사용해 다중 라벨 태깅 품질을 측정하고, 각 전략 및 RRF 융합을 별도 ablation으로 검증함으로써 태그당 근거 제공과 점진적 성능 저하를 보장한다.
Action Items

  • DevOps 파이프라인에서 구성 파일의 보안 민감도를 세 가지 병렬 전략과 RRF 융합으로 분류해 규칙 기반 스캐너보다 높은 정확도와 추적성을 제공한다.
  • 의료 기록 필드 자동 라벨링에 상태 기반 멀티‑에이전트 그래프를 적용하고, 임상 코딩 가이드라인을 내부 지식베이스에서 검색해 규정 준수를 보장한다.
