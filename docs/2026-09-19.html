Reasoning Quality Matters: Combating Reasoning Collapse in LLM-based Embedding Learning

LLM 임베딩에 추론 품질 유지해 검색 성능 향상

배경과 위치
기존 임베딩 학습은 단순 특징 추출이나 지시 따르기에 머물러 LLM 추론을 손상시켰다. CoFree는 추론‑임베딩을 연계한 두 단계 프레임워크로, 정적 정렬을 넘어 추론‑가이드 검색을 구현한다. 이는 LLM 기반 검색 최적화 흐름에서 추론 품질을 보존하는 새로운 접근이다
실행가능성 7
깊이 6
  • · Embedding 특화가 LLM 추론을 억제해 검색 관련성을 떨어뜨리는 ‘reasoning collapse’ 현상이 발생한다.
  • · CoFree는 참고 기반 지도 학습 후 이중 보상 강화학습으로 추론 품질을 유지하면서 임베딩을 최적화한다.
  • · 실험에서 CoFree‑4B가 22개 데이터셋에서 nDCG@10을 평균 2.8점 향상시키며 실서비스에서도 일관된 개선을 보였다.
Action Items
  • LLM 코드 생성 모델에 참고 기반 지도 학습을 적용해 추론 능력을 회복하고 API 특화 성능을 높인다.
  • 추천 시스템 임베딩 학습에 이중 보상 강화학습을 도입해 정확도와 설명 가능성을 동시에 개선한다.
  • 이미지‑텍스트 멀티모달 검색에 CoFree 방식을 적용해 시각적 추론을 유지하면서 임베딩 정렬을 강화한다
