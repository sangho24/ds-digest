Critical-State RL: Diagnosing Trainable States for Multi-Turn Tool Use

멀티턴도구사용시학습가능한상태를정확히찾아성능향상

배경과 위치
멀티턴 도구 사용에서 단일 호출 오류가 전체 보상에 섞여 판단이 어려웠던 문제를 해결하기 위해, 이 논문은 로컬 보상과 nested sampling을 결합해 학습 가능한 상태를 진단한다. 이는 도구‑보강 LLM의 on‑policy 강화학습 흐름에 속하며, 기존 전체 보상 기반 튜닝 대비 상태‑레벨 미세조정을 가능하게 한다.
실행가능성 7
깊이 6
  • · 보상 변동만으로는 어느 호출이 학습 필요인지 구분하기 어렵다.
  • · Critical-State RL은 로컬 보상을 평가하고 nested sampling으로 행동 의존 변동을 분리한다.
  • · 선택된 상태를 contextual-bandit으로 학습하면 베이스라인 대비 최대 14% 성능 향상.
Action Items
  • 고객지원 챗봇이 외부 지식베이스를 호출할 때 Critical-State 진단으로 학습 대상 API 호출을 선정해 응답 정확도를 높인다.
  • 자율주행 차량의 경로 계획 단계에서 nested sampling을 이용해 행동에 의한 보상 변동을 분리, 불필요한 재학습을 줄인다.
