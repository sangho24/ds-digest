When Does Fine-Tuning Beat Prompting for Qiskit-to-CUDA-Q Translation? An Execution-Verified Study

LLM 파인튜닝, 양자 코드 변환 효율 시점

배경과 위치
양자 회로를 Qiskit에서 NVIDIA CUDA‑Q로 옮기는 비용을 줄이기 위해, 기존 텍스트 치환 방식의 한계를 드러내고 실행 결과(상태벡터 유사도 ≥0.999)로 정확성을 검증하는 640‑task 벤치마크를 제시한다. 연구는 파인튜닝(LoRA)이 일부 베이스 모델에서 프롬프트 기반보다 높은 번역 정확도를 보이며, 코드 변환 연구에서 실행‑기반 평가의 필요성을 강조한다.
실행가능성 7
깊이 7
  • · LoRA 파인튜닝이 일부 베이스 모델에서 프롬프트보다 높은 번역 정확도를 보이며, 특히 Qwen2.5‑Coder 7B에서 전체 및 보이지 않는 스타일 모두 우수함
  • · 640개의 작업을 실행 기반(상태벡터 충실도 ≥0.999)으로 검증하는 벤치마크를 도입해 텍스트 치환만으로는 해결되지 않는 문제를 드러냄
  • · 실제 QED‑C 커널에 대해서는 모든 모델이 0% 성공률을 기록해, 현재 LLM은 단순 파라메트릭 코드만 변환 가능함을 보여줌
Action Items
  • 실행 기반 정확도 검증 방식을 이용해 Python‑to‑Julia 코드 변환 시 단위 테스트 통과 여부로 번역 품질을 평가한다
  • 프롬프트와 LoRA 파인튜닝을 혼합해 의료 보고서 생성에 적용하면, 스타일 일관성은 유지하면서 정확도는 향상될 수 있다
  • 표면 규칙 기반 전처리기를 활용해 SQL 방언 간 변환을 먼저 수행한 뒤 LLM에 전달하면 복잡한 쿼리 변환 효율을 높일 수 있다

  • SaaS 플랫폼에서 이탈 예측과 업셀 기회 예측을 하나의 멀티태스크 모델로 묶어 운영 효율성을 높인다.
