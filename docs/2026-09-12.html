Generative Late-Interaction Embeddings For Visual Document Retrieval

시각 문서 검색에서 저장 효율을 크게 개선

배경과 위치
Late‑interaction 기반 시각 문서 검색은 정확도가 높지만 저장 비용이 큰 문제를 안고 있다. 기존 압축 방법은 저장 예산이 제한될 때 성능이 급격히 떨어졌다. 본 논문은 벡터의 저차원 매니폴드 구조를 이용해 소수의 벡터만 저장하고 디코더로 전체 임베딩을 재생성하는 GLIE를 제안함으로써 저장 효율과 검색 정확도 사이의 새로운 트레이드오프를 제시한다.
실행가능성 7
깊이 7
  • · 벡터가 단위 구면 위에 위치하고 5~6 차원의 매니폴드에 집중한다는 기하학적 특성을 발견했다
  • · k‑means 중심을 구 표면으로 정규화하면 MaxSim 점수 편향을 보정해 nDCG@5를 최대 +0.093 향상시킨다
  • · GLIE는 정규화된 중심으로부터 k≪N 개의 벡터를 학습해 인덱스로 사용하고, 디코더가 상위 후보를 전체 N 벡터로 복원해 저장‑효율적인 검색을 구현한다
Action Items
  • 추천 시스템에서 임베딩 압축 시 매니폴드 기반 중심 정규화 적용 → 저장량 감소와 유사도 유지
  • 오디오 핑거프린트 검색에 GLIE 방식을 적용해 페이지당 몇 개의 벡터만 저장하고 필요 시 전체 핑거프린트를 복원해 정확도 유지
  • 대규모 그래프 노드 임베딩을 클러스터별 저차원 기반으로 재구성해 저장 비용을 낮추고 쿼리 시 디코더로 전체 임베딩을 복원한다

SenseNova-U1.5: Towards Native Unified Visual Intelligence

통합 멀티모달 모델로 시각 AI 파이프라인 비용 절감

배경과 위치
기존 멀티모달 모델은 이미지 인코더와 VAE 등 별도 모듈에 의존해 복잡한 파이프라인과 해상도 제한을 겪었다. SenseNova-U1.5는 이러한 모듈을 제거하고 8B‑MoT 구조로 단일 엔드‑투‑엔드 학습을 구현해 4K 해상도까지 지원한다. 이는 멀티모달 이해·생성의 통합 모델 흐름에서 인코더‑프리·VAE‑프리 접근을 선도하는 연구이다.
실행가능성 6
깊이 7
  • · SenseNova-U1.5는 인코더와 VAE 없이 8B 파라미터 MoT 구조로 시각‑언어 이해·생성을 수행한다.
  • · 공간적으로 일관된 패치 재구성과 4K 네이티브 해상도 학습으로 이미지 품질·텍스트 렌더링을 크게 향상시켰다.
  • · 사후 학습에서 시각 미학·양언어 텍스트·인포그래픽·이미지 편집 전문가를 최적화하고 다중 전문가 온‑폴리시 증류로 통합했다.
Action Items
  • 공간적으로 일관된 패치 재구성을 의료 영상 분할 파이프라인에 적용해 경계 일관성을 높인다.
  • 다중 전문가 온‑폴리시 증류를 활용해 패션·전자제품 등 분야별 추천 모델을 하나의 통합 추천 시스템으로 결합해 추론 지연을 감소시킨다.
  • 인코더‑프리·VAE‑프리 아키텍처를 실시간 4K 영상 분석에 적용해 중간 압축 단계 없이 엔드‑투‑엔드 처리 효율을 높인다.
